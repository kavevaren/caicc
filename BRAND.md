# Orvina: brand kit

- **Name:** Orvina. Chinese name to be decided (option: 奥维娜 Àowéinà).
- **Tagline:** Belajar bersama, paham lebih dalam · Learn together, understand deeper · 一起学习，深入理解.
- **Meaning:** Latin *orbita* (orbit) + Sanskrit *vinaya* (guidance) = "a guided orbit".
- **Origin:** name and logo were generated by the 4 ModelScope models (prompts in `arsip/brand/prompt-brand-logo.md`).

## Logo files (in `brand/`; copy them to `assets/brand/` and never redraw them)

| File | Use |
|---|---|
| `orvina-icon-light.svg` (A) | Logo on light backgrounds; sidebar lockup. In dark mode its stroke becomes `#4DA8DA` |
| `orvina-app-icon.svg` (D) | Favicon, app icon, avatar, dark backgrounds |
| `orvina-lockup.svg/.png` | Icon + "Orvina" in Outfit Bold, for README, slides, documents |

## Colours and type

The full token table (light and dark, with tints) is in `DESIGN.md` §1.1. Every pair is contrast-checked against WCAG AA.

- **Fonts:** Outfit for headings, numbers and the logo; Inter for body text.
- **Accent `#F4A261`:** decorative only, never used for text.
- **Dark mode:** buttons on primary or success use text `#12121A`, because white fails the contrast check there.
